# Warden

Warden is a Solana smart-account browser-extension wallet: a self-custody wallet built around
programmable, contract-enforced accounts rather than a single signing keypair, designed to match
mainstream wallet UX (see spec §1) while adding the safety and recovery properties that smart
accounts make possible.

This is a pnpm monorepo. To get started, install dependencies and run the test suite from the
repo root:

```bash
pnpm install && pnpm test
```
