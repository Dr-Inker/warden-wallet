# Prior-art findings corpus

**Every review prompt in this phase must seed this file** (`docs/security/PRIOR-ART-FINDINGS.md`),
alongside `docs/security/INVARIANTS.md` and the named sibling files. It is the cheapest counter to
shared LLM blind spots on Solana-specific classes: two models can be confidently wrong together, and
agreement between them is a confidence signal, never evidence. Concrete, named, sourced bugs are what
break the correlation.

`scripts/review.sh` inlines this file into every prompt. If you write a review prompt by hand and omit
it, the round does not count.

## Sourcing notes (read before citing any of these in a finding)

- **Verified by direct read of the primary PDF:** `TOB-SQUADS-7`, `TOB-SQUADS-8`, `ND-SQD3-LO-01`,
  `CERTORA-H-01`, `TOB-SQUADS-LOG`.
- **LazorKit `LZR-ACC-*`:** the audit artefact
  `audits/2026-accretion-solana-foundation-lazorkit-audit-A26SFR1.pdf` was confirmed to exist on
  `main` of [lazor-kit/program-v2](https://github.com/lazor-kit/program-v2) (all 14 findings fixed,
  engagement closed 2 Feb 2026). One research pass could not re-verify the per-finding content and
  flagged the IDs UNVERIFIED; a second pass reporting from the report itself supplied the descriptions
  above and they agree with LazorKit's own code comments. **Treat the finding *classes* as solid and
  the exact severities as secondary.** Note the path is `audits/`, not `docs/audits/`.
- **Swig `SWIG-ACC-*`:** the Accretion report **is public** in the `swig-wallet` repo's `audits/`
  directory (`2025-accretion-anagram-swig-audit-A25ANA2.pdf`, 4 Critical / 3 High). An earlier
  research pass in this repo recorded it as "shared upon request" — that was wrong and is corrected
  here. The `ACC-C1` description is independently corroborated by LazorKit's own module doc, which
  names the lesson and the mitigation it adopted.
- **`CERTORA-H-01` is a different mechanism from `ND-SQD3-LO-01`,** not a second sighting of the same
  bug — a transaction-index/lifecycle race versus a creator-less seed derivation. The earlier wording
  in this file ("the identical failure mode") was wrong and is corrected in the table. They belong in
  the corpus as a pair because they bound the same class from both ends, and `WRD-BUF-01`/`-02` need a
  test for each mechanism.
- **Local aliases vs native ids.** The left-hand column is the **local alias** this repo uses in
  `invariants.jsonl` `prior_art` and in a finding's `prior_art_cited`; the second column is the id the
  source report itself uses. They differ deliberately: `ACC-C1` is ambiguous across the LazorKit and
  Swig reports (both have one), so the ledger namespaces them `LZR-` and `SWIG-`. **The Trail of Bits
  numbering is UNCONFIRMED**: this repo's research recorded the unauthenticated-`create_key` finding
  as `TOB-SQUADS-7` and the ephemeral-seed finding as `TOB-SQUADS-8`, but the report's own numbering
  may be one lower (`-6` / `-7`). The aliases stay as they are — they are already cited across the
  ledger and renaming them would silently orphan every citation — but **do not quote a native TOB
  number in a finding until someone has re-opened the PDF**.
- **The `ARGENT-ZERO-GUARDIAN` delay** is documented as 24–48 h in overview sources and specifically
  36 h in the incident write-up.
- The IDs in this file are the values a finding may put in `prior_art_cited`. **Do not invent new
  ones in a review**; if a class has no ID here, say so in `rationale` and open a row.

## Licensing constraint (binding, and it is not a footnote)

Only LazorKit `program-v2` is **MIT**. **Swig and Squads v4 are AGPL-3.0, Backpack is GPL-3.0 —
reference only.** Copyleft attaches to the combined work and shipping an extension triggers GPL §5;
AGPL §13 over on-chain execution is legally untested. **Any reuse of non-MIT prior art requires a
counsel-approved reuse policy before code lands** — "we reimplemented it clean-room" is a claim
counsel evaluates, not a conclusion an engineer or a review prompt can reach.

There is a standing review-prompt item for this: *"does this diff reproduce structure, naming or
comments recognisably from Swig / Squads / Backpack?"* It reduces exposure; it does not settle
derivative-work law. Do not reuse names or marks either way. Attribution lands in
`THIRD_PARTY_NOTICES.md`.
